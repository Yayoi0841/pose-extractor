はじめに

動画からタメとヒットのポーズを抜き出して、パワポにするツールです。

  1. 動画を入れる：画面にドラッグ
  2. 探す：Space 再生／←→ 1コマ
  3. 登録：1 タメ／2 ヒット
  4. 次へ：N 次のモーション
  5. 書き出す：「ファイル → パワポを書き出す」

自動で保存されます。? でショートカット一覧。

画面の見かた

① メニュー・ツール
② 動画
③ ビューポート
④ FB
⑤ タイムスライダー・再生
  • ① ファイル・ヘルプ・ペンの設定
  • ② 動画の一覧（クリックで切り替え）
  • ③ 動画を見る・描く場所
  • ④ メモ・レイヤー（ポーズ一覧は「表示」から出せる）
  • ⑤ 再生・範囲・表示の切り替え

動画を入れる・整理

  • 入れる：ドラッグ、または左上「＋」
  • 画像もOK（1コマの動画として入る）
  • 並べ替え：一覧をドラッグ
  • フォルダー：Ctrl+G（📁 で空のフォルダー）
  • 切り替え：Ctrl+↑↓
  • 未接続と出たら：同じ動画を入れ直す

再生

  • Space 再生／停止
  • ←→ 1コマ（Shiftで5コマ）
  • K＋ドラッグ：スクラブ
  • 範囲：タイムスライダー下のバーの端をドラッグ
  • スロー：右下「1x」で 1/32 まで

キーとポーズ

  • S キーを打つ／Delete 消す
  • ,. 前／次のキーへ
  • 1 タメ（橙）／2 ヒット（緑）
  • N モーション追加／↑↓ 切り替え
  • パワポ：「ファイル → パワポを書き出す」（日目を聞かれます）
  • 登録の確認・やり直し：「表示 → ポーズ一覧」
  • Maya用：「ファイル → Maya 用に書き出す」（フレーム一覧と 1-01.jpg など）
  • 動画（MP4）：「ファイル → MP4 で書き出す」。ペン・メモ・置いた画像やサブ動画・軌道をそのまま焼き込みます。FBのコマは数秒止めて見せられます（音は入りません）
  • タイムスライダーにキー間のコマ数（6f など）が出ます

見やすくする

  • 拡大：ホイール／Ctrl+Space＋クリック
  • 移動：Space＋ドラッグ
  • 全体表示：F
  • 追従：I（キャラを囲む）／Shift+I 選び直し
  • 反転：Shift+H
  • ゴースト：G（前後のキーを半透明で）
  • キーのみ再生：Shift+Alt+B
  • オニオンスキン：O（前後のコマの動いた所だけ赤・緑で）
  • 重ねる：別の動画を透かす（下の段のボタン）
  • 2画面：「表示 → 2画面で並べる」
  • 補助線：「表示」から中心線・三分割
  • 集中モード：Shift+Y（上のツールとペンの設定はそのまま使える）

サブ資料を置く

  • 画像：Ctrl+V、または動画の上にドロップ
  • サブ動画：左の一覧から動画をビューポートへドラッグ（「表示 → サブ動画を置く」でも）
  • V でドラッグ移動・角で拡大縮小。画面の外にも置ける（ホイールで縮小すると見やすい）
  • サブ動画は下のバーで再生・位置・🔗同期（メインと一緒に再生）
  • Delete で外す／Ctrl+Z で戻す
  • レイヤー：左の一覧で動画の下に並ぶ。👁 で表示切替・ドラッグで重なり順・ダブルクリックで名前
  • 動画の「▼ 資料N」でレイヤーをしまう／出す（しまっても画面からは消えません）

置いた物は全コマ共通で、ベース動画ごとに覚えます。「ペンを隠す」（H）では消えません。

文字を入れる

  1. T（または上の「T」）で文字ツール
  2. 入れたい所をクリックして入力（Enter で改行）
  3. Esc か外をクリックで確定
  • 色・大きさ・「ふち／黒帯／白帯」・太字は上のバーで。選んでいる文字にもすぐ反映
  • 選択ツールでドラッグ＝移動、角＝拡大縮小、ダブルクリック＝直す、Delete＝消す
  • ペンと同じくそのフレーム・レイヤーに入り、PNG・MP4 にも入ります

軌道と角度

  • A 軌道：追いたい部位をクリック → 自動で次のコマへ
  • 「＋ 新しい軌道」で別の部位（色が変わる）
  • R 角度：ドラッグで線（2本目で差が出る）
  • 右クリックで点・線を消す／Ctrl+Z で戻す

FB（ペン・メモ）

  • B ペン／E 消しゴム／V 選択
  • [] 太さ／Shift＋クリックで直線
  • Ctrl+Z 戻す
  • M メモを書く
  • Ctrl+V 画像を置く（「サブ資料を置く」参照）
  • H ペンを隠す／Shift+M メモを隠す
  • Ctrl+Shift+S 今のコマを画像で保存

描いた線はそのコマだけに残ります。筆圧はペンタブで自動（「濃さも」で濃淡も変わる）。

追加のFBが来たら

  • FBタブの＋ 新しいFB：メモだけ新しくなる（ペンの線はそのまま）
  • 一覧で回を切り替え
  • 前回を薄く：前の回のメモを灰色で表示

保存

  • 自動で保存（このPCのブラウザの中だけ）
  • 前の作業：「ファイル → 最近の作業」
  • バックアップ：「ファイル → プロジェクトを保存」
  • 動画を残す日数：「ファイル」から変更

ブラウザの履歴削除で作業も消えます。大事な作業はプロジェクト保存を。

動画はどこに保存される？

このPCのブラウザの中だけです。ネットには上がりません。

  • 外に送られない：ページの設定で外部との通信を止めています。GitHub に置いてあるのはツールのプログラムだけで、動画は1つも入っていません。
  • ほかの人には見えない：ブラウザは保存場所をサイトごとに分けて鍵をかけています。ほかのサイト・ほかのPC・このツールを使う友達からは読めません。
  • PCの中の場所（Chrome）：
    %LOCALAPPDATA%\Google\Chrome\User Data\Default\IndexedDB
    の中の「https_yayoi0841.github.io_0」で始まるフォルダ。動画は番号だけの名前のファイルで入っています。
  • Edge は Google\Chrome が Microsoft\Edge になります。
  • 中身・容量・場所は「ファイル → 保存しているデータを確認」で見られます。

消えるとき

  • 決めた日数さわらなかった（ファイル → 動画を残す日数）
  • 「ファイル → この作業を削除」
  • ブラウザの「閲覧履歴データの削除」

気をつけること

  • 同じPC・同じWindowsアカウント・同じブラウザを使う人は、このツールを開けば中身が見えます。共用PCでは使い終わったら作業を削除。
  • 動画を残したくないときは「ファイル → 動画もこのPCのブラウザに保存」をオフ（次に開くときは入れ直し）。

安全

  • 外部とは通信しません
  • 本物の動画・画像だけ読み込みます
  • PCには何もインストールしません

会社の映像で作ったファイルは社外に出さないように。
